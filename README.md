# Boids Avoidance Testing
By Tyler Jeffrey

## Overview
This project uses the Boids flocking algorithm in order to test obstacle avoidance. It is themed off of space.

## Mechanics
This project requires no input from the user as it is a test. Simply press the player button and you will automatically begin to view the boids in action.

## Installation & Setup
1.  Clone this repository to your local machine.
2.  Open the project in **Unity 2022.3 LTS** (or newer).
3.  Ensure all scenes are added into **Build Settings**.
4.  Press **Play** in the `MainMenu` scene to begin the experience.
